# 조리실 알림판

카카오톡 알림의 원문 본문을 조리실 외부 모니터에 크게 표시하는 Android 앱입니다.
키워드를 분석하거나 요약하지 않으며 Android 공식 `NotificationListenerService`로
카카오톡이 알림에 넣은 문자열을 그대로 수신합니다.

## 화면 구성

- 휴대폰: 외부 모니터 상태, 채팅방 선택, 자동답장, 대기 문구, 경보 테스트 및 내용 삭제
- 외부 모니터: `Presentation` API로 모니터 고유 해상도 전체화면 출력
- 대기 중에는 편집 가능한 대기 문구 옆에 현재 시각을 초 단위로 갱신해 동작 상태 표시
- 모니터 미연결 시 휴대폰 제어 화면은 계속 동작

## 알림 동작

- 카카오톡 패키지(`com.kakao.talk`)의 실제 메시지 알림만 수신
- 발신자와 수신 시각은 표시하지 않고 알림 본문만 수신 순서대로 누적
- 휴대폰에서 제외 단어를 한 줄에 하나씩 편집 가능하며 발신자 또는 원문에 포함되면
  표시·경보에서 제외(기본 제외 단어: `영양사`)
- 필터 메시지에는 `필터링되어 알림판에 뜨지 않았습니다.`라고 자동답장하며 문구 편집 가능
- 알림 갱신 시 이미 받은 메시지는 지문 값으로 중복 제거
- 새 메시지마다 큰 글씨 표시, `띵동-띵동` 경보음, 붉은 테두리 점멸
- 소리는 짧게 자동 종료되고 테두리는 8초 후 자동 종료
- 내용은 다음 끼니 구간까지 유지
- 내용이 화면 높이를 넘으면 위에서 아래로 자동 스크롤한 뒤 처음으로 돌아가 반복
- 메시지 행마다 흰색·연회색 배경을 번갈아 표시해 줄 경계를 구분
- 앱에는 네트워크 권한이 없으며 내용은 앱 전용 로컬 저장소에만 보관

## 채팅방 선택과 자동답장

- 실제 카카오톡 알림의 대화방별 `shortcutId`를 기준으로 방을 구분
- 한 번 이상 알림이 도착했거나 현재 알림창에 남아 있는 방이 휴대폰 목록에 표시
- 특정 방을 고르면 이후 그 방의 카톡만 모니터에 누적하고 경보 실행
- 방을 바꾸면 이전 방의 현재 끼니 내용은 화면에서 삭제
- 자동답장은 기본적으로 꺼져 있으며, 켜면 현재 채팅방 필터를 통과한 모든 새 알림에 적용
- 채팅방 필터가 `모든 카카오톡 채팅방`이면 알림이 활성화된 모든 방에 자동답장
- 정상 표시 시 `알림화면에 띄웠습니다.`, 모니터 미연결 시
  `문제가 발생했습니다. 직접 전달해 주세요.`를 카카오톡 알림의 답장 기능으로 전송
- 두 답장 문구는 휴대폰 설정 화면에서 편집 가능

## 끼니 구간과 초기화

- 휴대폰의 `알림판 초기화 시간`에서 조식·중식·석식 시각을 분 단위로 설정
- 기본값은 조식 09:00, 중식 13:00, 석식 21:00
- 각 초기화 시각에 이전 내용이 사라지고 다음 끼니 알림판으로 전환
- 세 시각은 하루 안에서 `조식 < 중식 < 석식` 순서로만 저장 가능

모니터 제목 예시: `2026.9.14 석식 식이 변경사항 (다음 초기화 21:00)`

## 화면 자동 복구

- 알림 수신 서비스가 외부 모니터 창을 직접 유지하므로 휴대폰에서 다른 앱을 사용해도 계속 표시
- HDMI 모니터가 새로 연결되거나 연결이 바뀌면 자동으로 전체화면 재생성
- 15초 감시로 비정상적으로 닫힌 모니터 창을 복구
- 휴대폰 재부팅, 사용자 잠금 해제, 앱 업데이트 후 알림 서비스를 다시 연결
- 다른 전체화면 알림이 잠시 위를 덮어도 닫힌 뒤 기존 알림판이 남아 있음
- 외부 모니터 연결 중 CPU 절전 방지 잠금을 유지해 휴대폰 화면 소등 중에도 서비스와 출력 유지 시도
- Android는 기본 화면과 유선 외부 화면의 전원을 앱이 개별 제어할 수 없으므로,
  `휴대폰 화면 검게 유지` 모드에서 OLED를 검게·최저 밝기로 유지하면서 모니터 출력 지속
- 실제 전원 버튼으로 잠그면 삼성 시스템이 외부 출력도 끌 수 있어 검은 화면 모드 사용 권장

## 빌드

Android SDK 36과 JDK 17을 사용합니다.

```powershell
./gradlew.bat assembleDebug lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

## GitHub OTA 업데이트

- 휴대폰 설정 화면 상단의 `업데이트 확인` 버튼으로 최신 GitHub Release 확인
- 새 버전이면 릴리스 APK를 내려받고 Android 패키지 설치 화면 실행
- 최초 한 번은 Android 설정에서 이 앱의 `알 수 없는 앱 설치` 허용 필요
- Git 태그 `vX.Y.Z`를 푸시하면 GitHub Actions가 동일한 서명으로 APK를 빌드해 Release에 게시
- 다운로드 파일은 GitHub가 제공하는 SHA-256 값이 있을 경우 설치 전 검증
- v0.14.1: 실제 기기 OTA 설치 흐름 검증 릴리스
- v0.14.2: OTA 서명키를 빌드에 명시적으로 고정하고 인증서 지문 검증 추가
